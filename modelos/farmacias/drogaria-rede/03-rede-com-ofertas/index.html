Modelo com demonstração

Rede com Ofertas

Um site para redes de drogarias divulgarem campanhas e ofertas da rede, com a loja mais próxima recebendo o pedido pelo WhatsApp.

Nível 3 Rede de drogarias Atendimento pelo WhatsApp
Solicitar orçamento Abrir demonstração Voltar para modelos

Resumo

  • Tudo do modelo Rede com Unidades.
  • Vitrine de ofertas da rede com validade.
  • Ofertas regionais por cidade ou por loja.
  • Sem carrinho nem pagamento online.

O que vai ter

O que este modelo inclui

Tudo isso já funciona na demonstração navegável, com uma empresa fictícia.

Ofertas da rede

Encarte digital com as ofertas que valem em todas as lojas.

Ofertas por região

Promoções que valem só em algumas cidades ou unidades.

Pedido na loja mais próxima

O cliente escolhe a loja e envia o pedido para o WhatsApp dela.

Campanhas sazonais

Páginas de campanha para datas como inverno e Dia das Mães.

Unidades com filtro

A mesma busca por cidade do modelo Rede com Unidades.

Link para as redes sociais

Cada oferta tem um link próprio para compartilhar.

Para quem é

Para quem este modelo é indicado

Rede com encarte semanal

Para quem já faz ofertas e quer levar o encarte para a internet.

Rede com marketing próprio

Para quem roda campanhas e precisa de páginas para elas.

Rede que quer vender mais por loja

Para direcionar o pedido para a unidade certa.

Limites deste modelo

O que este modelo não faz

  • Não tem carrinho nem pagamento online.
  • Não controla estoque por loja.
  • Não se integra ao ERP da rede.
